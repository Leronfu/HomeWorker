## 🛠 Технический стек
- **Язык:** Python 3.10+
- **Фреймворк для бота:** `aiogram 3.x` (использование Router, FSM для админки, Inline и Reply клавиатур).
- **База данных:** `SQLite` + `aiosqlite` (лёгкая локальная БД, не требующая сложной установки сервера).
- **Планировщик задач:** `APScheduler` (`AsyncIOScheduler`) — для обновления расписания по субботам в 15:00 и для публикации докладов в случайное время.
- **Конфигурация:** `python-dotenv` (хранение `BOT_TOKEN` и `ADMIN_IDS` в файле `.env`).

## ⚙️ Функциональные требования

### 1. Пользователи и Регистрация
- При нажатии `/start` бот сохраняет `telegram_id` и `username` пользователя в БД (это необходимо для массовой рассылки уведомлений о докладах).
- При первом входе бот просит студента ввести свои **Имя и Фамилию** (сохраняется в БД), чтобы при записи на доклад отображалось реальное имя студента.

### 2. Расписание (Понедельник — Суббота)
- В БД хранятся два слота расписания: `current_week` (текущая неделя) и `next_week` (следующая неделя), разбитые по дням недели (Пн–Сб) или единым красиво отформатированным текстом по дням.
- **Админка:** Админ может заранее заполнить расписание на `next_week`, а также в любой момент отредактировать любой день в `current_week` (если пары перенесли или отменили).
- **Авто-обновление:** Каждую субботу ровно в **15:00** (по локальному времени/МСК) планировщик `APScheduler` копирует данные из `next_week` в `current_week`, очищает `next_week` и (опционально) уведомляет админа.

### 3. Домашнее задание (ДЗ)
- Студент нажимает кнопку «📚 Домашнее задание» -> выбирает предмет из списка 10 дисциплин.
- Бот выводит все актуальные домашние задания по этому предмету (Дата сдачи + Текст задания).
- **Админка:** Админ может добавить новое ДЗ (выбрать предмет -> ввести дату -> ввести текст), отредактировать существующее или удалить старое/выполненное ДЗ.

### 4. Доклады и система «Честного дропа» (Random Time Release)
- **Проблема:** За простые темы докладов идёт борьба, сложные никто не берёт. Нужен эффект неожиданности, но с равными шансами.
- **Как работает для Админа:**
  1. Админ заходит в управление докладами -> выбирает предмет.
  2. Вводит дату семинара и список вопросов/тем (например, списком, где каждая строка — отдельная тема).
  3. Указывает **дату публикации (дропа)** этих тем в боте.
  4. Бот автоматически генерирует **случайное время** в пределах дневного интервала этой даты (например, между 10:00 и 20:00, чтобы не будить людей ночью). Точное время скрыто от студентов (и даже админу можно не показывать или показывать по желанию).
- **Как работает в момент X (Рассылка):**
  1. Когда наступает сгенерированное случайное время, `APScheduler` меняет статус тем с `pending` на `published`.
  2. Бот делает **массовую рассылку** всем зарегистрированным пользователям в личные сообщения (и в общую беседу группы, если бот туда добавлен): *"🔥 Выложены темы докладов по предмету «[Название предмета]»! Скорее заходите в раздел «Доклады», чтобы занять тему!"*
- **Как работает для Студента:**
  1. Студент жмёт «🎤 Доклады» -> выбирает предмет.
  2. Ему показывается сообщение со списком всех тем, датой выступления и статусом:
     - `1. Тема вопроса — ✅ Занято (Иван Иванов)`
     - `2. Тема вопроса — 🟢 Свободно`
  3. Ниже под сообщением находятся Inline-кнопки только со **свободными** номерами тем.
  4. При нажатии на кнопку тема закрепляется за студентом в БД (с защитой от одновременного нажатия: если кто-то успел на долю секунды раньше, второму выводится всплывающее окно `alert`: *"Упс! Эту тему только что забрали"*). Сообщение со списком тут же обновляется.
  5. Также у студента должна быть возможность отказаться от темы (или через админа), если он нажал случайно.
