# HomeWorker — Telegram-бот для учебной группы (Психология)

Бот-помощник для старосты и студентов университетской группы:
- 📅 Расписание занятий с авто-обновлением каждую неделю
- 📚 Домашние задания по 10 профильным предметам
- 🎤 Организация докладов с системой честного случайного дропа тем

---

## 🚀 Быстрый старт и настройка окружения

### 1. Как получить токен бота
1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте ему команду `/newbot`.
3. Введите название для бота (например: `Психологи 3 курс | Помощник`).
4. Введите юзернейм для бота, который обязательно оканчивается на `bot` (например: `psy_group_homework_bot`).
5. `@BotFather` пришлёт сообщение с токеном вида:
   `7123456789:AAH...v8`
   Скопируйте этот токен.

### 2. Как узнать свой Telegram ID (для прав старосты)
1. Откройте бота [@userinfobot](https://t.me/userinfobot) (или [@myidbot](https://t.me/myidbot)).
2. Нажмите кнопку **Start** (или отправьте любое сообщение).
3. Бот ответит сообщением с вашим числовым `Id` (например, `123456789`). Скопируйте это число.

### 3. Создание файла настроек `.env`
1. В корне проекта скопируйте файл `.env.example` и назовите его `.env`:
   ```bash
   cp .env.example .env
   ```
2. Откройте `.env` в текстовом редакторе и вставьте полученные данные:
   ```env
   BOT_TOKEN=вставьте_сюда_токен_от_BotFather
   ADMIN_IDS=вставьте_сюда_ваш_id
   ```
   *(Если старост или администраторов несколько, перечислите их ID через запятую: `ADMIN_IDS=123456789,987654321`)*

### 4. Установка зависимостей
Рекомендуется создать виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
