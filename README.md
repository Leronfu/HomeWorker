# 🎓 HomeWorker — Telegram Mini App (TG App) для учебной группы (Психология)

**HomeWorker** — это современный цифровой помощник для старосты и студентов университетской группы факультета психологии. Весь основной функционал вынесен в интерактивное мобильное веб-приложение **Telegram Mini App (Web App)**, а бот выступает надёжным каналом мгновенных push-уведомлений и организатором системы «честного дропа» докладов.

---

## 🌟 Возможности приложения

### 1. 📅 Расписание занятий (Пн – Сб)
- **Просмотр для студентов:** удобное переключение между «Текущей» и «Следующей» неделями.
- **Управление для старосты:** быстрое редактирование любого дня недели прямо из приложения через модальное окно.
- **Автоматический перенос:** каждую субботу ровно в **15:00 (МСК)** планировщик `APScheduler` автоматически копирует расписание со следующей недели на текущую, очищает слот следующей недели и отправляет старосте уведомление.

### 2. 📚 Домашние задания
- **10 профильных психологических дисциплин:**
  1. Психология эмоций и мотивации
  2. Психология личности
  3. Психодиагностика
  4. Экспериментальная психология
  5. Статистика
  6. Методология
  7. Медицинская психология
  8. Социальная психология
  9. Основы управления интеллектуальной собственностью
  10. Основы психологической помощи
- **Фильтрация:** удобные горизонтальные кнопки-пилюли для фильтрации заданий по предметам.
- **Сроки сдачи:** наглядные бейджи дедлайнов (например: *«К 25 ноября»*).
- **Панель старосты:** добавление нового задания, редактирование и удаление выполненных заданий в один клик.

### 3. 🎤 Доклады и система «Честного дропа» (Random Time Release)
- **В чём проблема:** за простые темы докладов идёт борьба, сложные темы никто не берёт. Стандартное время выкладывания известно не всем.
- **Как это решено:**
  1. Староста вводит дату семинара, список тем и **дату дропа** (например: `10.12.2026`).
  2. Сервер автоматически генерирует **случайное время** в дневном интервале этой даты (между 10:00 и 21:00 МСК). Точное время публикации держится в секрете.
  3. В момент наступления случайного времени планировщик автоматически переводит темы в статус опубликованных, и бот делает **мгновенную массовую рассылку всем студентам группы** в личные сообщения:
     > *«🔥 ВЫЛОЖЕНЫ ТЕМЫ ДОКЛАДОВ по предмету ...! Скорее открывайте приложение, чтобы занять тему!»*
  4. Студенты открывают Mini App и видят список свободных тем:
     - `🟢 Свободно` — яркая кнопка **«Занять тему»**.
     - `✅ Занято (Иван Иванов)` — тема закреплена за студентом.
  5. **Атомарная защита от одновременных кликов:** если два студента нажмут на кнопку одновременно с разницей в доли секунды, сервер закрепит тему за первым, а второму покажет предупреждение: *«Упс! Эту тему только что занял другой студент»*.
  6. **Отказ от темы:** студент может в любой момент отказаться от ошибочно выбранной темы, и она снова станет доступна одногруппникам.
  7. **Досрочная публикация:** староста при необходимости может опубликовать темы досрочно кнопкой *«🚀 Выложить сейчас»*.

### 4. ⚙️ Панель старосты
- Единый дашборд с быстрыми действиями (создание дропа тем, публикация ДЗ, заполнение расписания).
- Права старосты выдаются автоматически на основе списка `ADMIN_IDS` из `.env`.

## 🛠 Технический стек

- **Бэкенд:** Python 3.10+ (macOS, виртуальное окружение `.venv`).
- **Telegram Bot API:** `aiogram 3.x` (Router, FSM, MenuButtonWebApp, WebAppInfo).
- **Встроенный веб-сервер:** `aiohttp.web` (работает в едином процессе и цикле событий с ботом, единый порт).
- **База данных:** локальная `SQLite` + `aiosqlite` (6 связанных таблиц, поддержка внешних ключей и транзакций).
- **Фоновый планировщик:** `APScheduler` (`AsyncIOScheduler`, часовой пояс `Europe/Moscow`).
- **Фронтенд Mini App:** HTML5, современный Vanilla CSS со стеклянным дизайном (**Glassmorphism**, темы Telegram, шрифты Inter), чистый Vanilla JS с интеграцией `telegram-web-app.js` и виброоткликом (**Haptic Feedback**).

## 🚀 Инструкция по запуску и настройке

### 1. Подготовка окружения (macOS)
В терминале перейдите в папку проекта:
```bash
cd ~/Git/HomeWorker
```

Создайте виртуальное окружение и установите зависимости:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

---

### 2. Получение токена бота и ID старосты

#### А. Токен Telegram-бота:
1. Откройте в Telegram официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите название бота (например: `Психологи 3 курс`).
4. Укажите юзернейм, оканчивающийся на `bot` (например: `psy_hw_assistant_bot`).
5. Скопируйте полученный API-токен (вида `7123456789:AAH...`).

#### Б. Telegram ID старосты:
1. Откройте бота [@userinfobot](https://t.me/userinfobot) (или [@myidbot](https://t.me/myidbot)).
2. Нажмите **Start**.
3. Бот вернёт ваш числовой `Id` (например: `123456789`).

---

### 3. Настройка файла конфигурации `.env`
Создайте файл `.env` на основе шаблона `.env.example`:
```bash
cp .env.example .env
```
Откройте файл `.env` в любом редакторе и укажите:
```env
# Токен бота от @BotFather
BOT_TOKEN=7123456789:AAH...ваш_токен

# Telegram ID старосты (если старост несколько, перечислите через запятую: 123456,789012)
ADMIN_IDS=123456789

# База данных SQLite (по умолчанию: homeworker.db)
DB_PATH=homeworker.db

# Порт встроенного веб-сервера Mini App
WEB_HOST=0.0.0.0
WEB_PORT=8080

# URL приложения для открытия в Telegram (подробнее ниже)
WEB_APP_URL=http://localhost:8080
```

### 4. Запуск 24/7 без установки cloudflared: Связка Alwaysdata + Cloudflare Workers

Если вы не хотите устанавливать `cloudflared` на свой компьютер и держать Mac постоянно включенным, используйте полностью бесплатную облачную связку **Alwaysdata + Cloudflare Workers**:

#### Шаг А. Бэкенд на Alwaysdata (бесплатный хостинг Python с постоянным HTTPS):
1. Зарегистрируйтесь на сайте [alwaysdata.com](https://www.alwaysdata.com) (бесплатный тариф).
2. Вы получите постоянный адрес вида: `https://ВАШ_АККАУНТ.alwaysdata.net`.
3. В панели Alwaysdata перейдите в **SSH** (или откройте веб-терминал) и склонируйте репозиторий:
   ```bash
   git clone https://github.com/Leronfu/HomeWorker.git
   cd HomeWorker
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   ```
4. В файле `.env` укажите ваш `BOT_TOKEN`, `ADMIN_IDS` и `WEB_APP_URL` (URL вашего воркера, полученный на шаге Б).
5. В панели Alwaysdata в разделе **Web > Sites** создайте сайт:
   - **Type:** `Custom (TCP/IP port)`
   - **Command:** `source .venv/bin/activate && python3 main.py`
   - *(Или в разделе **Environment > Programs** добавьте фоновую программу).*

#### Шаг Б. Cloudflare Worker (CDN и обратный прокси без консоли):
1. В личном кабинете [dash.cloudflare.com](https://dash.cloudflare.com) перейдите в **Workers & Pages** -> **Create application** -> **Create Worker**.
2. Назовите его, например, `homeworker-app` и нажмите **Deploy**.
3. Нажмите **Edit code** (Быстрое редактирование в браузере) и вставьте содержимое файла [cloudflare/worker.js](file:///Users/leronfu/Git/HomeWorker/cloudflare/worker.js).
4. Замените строку `DEFAULT_ALWAYSDATA_URL` на ваш адрес:
   ```javascript
   const DEFAULT_ALWAYSDATA_URL = "https://ВАШ_АККАУНТ.alwaysdata.net";
   ```
5. Нажмите **Save and Deploy**. Вы получите постоянную ссылку `https://homeworker-app.ваш-логин.workers.dev`.
6. Укажите эту ссылку в `@BotFather` через команду `/setmenubutton` (или `/newapp`).

Теперь Mini App открывается со сверхбыстрой скоростью Cloudflare, запросы надежно идут на сервер Alwaysdata, а бот работает круглосуточно 24/7!

## 📱 Как пользоваться ботом

### Студенту:
1. Нажмите `/start` в Telegram.
2. При первом входе введите свои **Имя и Фамилию** (чтобы при записи на доклад отображалось реальное имя).
3. Нажмите кнопку **«📱 Открыть HomeWorker»** в сообщении или кнопку меню слева от поля ввода.
4. Откроется Mini App:
   - Вкладка **«📅 Расписание»**: смотрите пары на сегодня и на всю неделю.
   - Вкладка **«📚 ДЗ»**: выбирайте предметы и смотрите задания и дедлайны.
   - Вкладка **«🎤 Доклады»**: когда придёт уведомление о дропе тем, нажимайте **«Занять тему»**.

### Старосте:
1. При первом старте после ввода имени система автоматически выдаст права администратора на основе `ADMIN_IDS`.
2. В приложении появится бейдж **«👑 Староста»** и вкладка **«⚙️ Староста»**.
3. **Редактирование расписания:** на вкладке «Расписание» возле каждого дня появится кнопка *«✏️ Изменить»*.
4. **Добавление ДЗ:** на вкладке «ДЗ» нажмите кнопку *«➕ Добавить ДЗ»* и заполните форму.
5. **Создание дропа докладов:**
   - Нажмите *«➕ Создать пул тем»*.
   - Выберите предмет, введите дату семинара, дату публикации дропа (например: `15.11.2026`) и список вопросов (каждый с новой строки).
   - Бот сам выберет случайное время и запланирует честную рассылку.
